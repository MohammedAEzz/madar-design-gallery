# Panorama — website design proposals

A static gallery presenting ten homepage design proposals for the Panorama
construction company website. Opening `index.html` lists every proposal with a screenshot,
a reference code and a link to the full interactive prototype.

- `index.html` — the gallery (Arabic, RTL).
- `designs/` — the ten prototypes, each self-contained with its own CSS/JS/images.
- `assets/shots/` — desktop and mobile screenshots used by the gallery cards.

The projects, figures and imagery inside the prototypes are placeholder content
used to demonstrate layout only, and will be replaced with real company content.

Published with GitHub Pages from the `main` branch.
